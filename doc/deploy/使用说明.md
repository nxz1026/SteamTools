# Steam++ Accelerator（仅代理版）使用说明

安装位置：`C:\SteamToolsAccelerator\`
主程序：`C:\SteamToolsAccelerator\Steam++.Accelerator.exe`

## 快速开始

右键 `launch.bat` → 「以管理员身份运行」（或直接双击，脚本会自己申请提权）。

启动成功后**黑窗口会自动消失，程序缩到右下角托盘区**——不用管它，加速已经在跑了。

右键托盘图标有两个菜单项：

| 菜单项 | 作用 |
|---|---|
| 显示控制台 | 把隐藏的黑窗口调出来看日志 |
| 退出 | 撤销系统设置 → 停止代理 → 关闭 |

**停止请用托盘菜单的「退出」**，不要再按 `Ctrl+C`——窗口已经被隐藏，没有地方按了。
想让它一直显示窗口，用 `launch.bat console system` 启动。

> 启动失败（一闪就没了、也没出托盘图标）时，看日志：
> `%LOCALAPPDATA%\Steam++Accelerator\Cache\Logs\accelerator-<日期>.log`

首次运行会自动生成一张自签根证书并装进 `LocalMachine\Root`（需管理员），
浏览器和 .NET 客户端之后就能信任 MITM 解密流量。

## 规则配置文件

**加速规则全部由一个 JSON 文件控制，随时可以改，改完重启程序即可生效。**

| 项 | 路径 |
|---|---|
| 规则配置 | `%LOCALAPPDATA%\Steam++Accelerator\accelerate-rules.json` |

程序启动时**只读这个文件，不联网**。文件里每条规则长这样：

```json
{
  "name": "Steam 商店",
  "enabled": true,
  "matchDomainNames": "store.steampowered.com;api.steampowered.com;...",
  "forwardDomainNames": "steamstore.rmbgame.net",
  "listenDomainNames": "store.steampowered.com;...",
  "port": 443,
  "proxyType": 0
}
```

要改哪些规则加速、哪些不加速，改 `enabled` 就行：

```json
"enabled": true    // 启用这条规则
"enabled": false   // 停用这条规则
```

其它字段也能改，但一般不用动：

| 字段 | 含义 |
|---|---|
| `name` | 规则名称，也是与官方规则集比对的键，**不要改** |
| `enabled` | 是否启用 |
| `matchDomainNames` | 命中域名（分号分隔） |
| `forwardDomainNames` | 转发目标（国内加速节点） |
| `listenDomainNames` | hosts 模式写入 hosts 的域名 |
| `port` | 目标端口 |
| `proxyType` | 0=本地代理 1=重定向 2=直连成功 3=服务端代理 |
| `items` | 子规则，用于更细的路径匹配 |

文件开头有 `//` 注释，也可以自己加注释，程序会跳过。

**每条规则下面都有一行中文注释，说明这条规则的作用**，例如：

```json
    {
      "name": "Steam 商店",
      "enabled": true,
      ...
    },
    // 本地代理：store.steampowered.com 等 5 个域名 直连 steamstore.rmbgame.net 取数据，保留原始 Host
```

**默认启用 Steam + GitHub**（共 17 条）。想启用别的规则（比如 Twitch、Docker Hub、
Google Fonts 等），把对应条目的 `enabled` 改成 `true` 即可。

### 拉取官方最新规则

```bat
Steam++.Accelerator.exe --mode dns --refresh-rules
```

会重新从官方接口抓一次规则并更新配置文件，**你改过的 `enabled` 状态按规则名保留**。

### 其它命令行参数

```
Steam++.Accelerator.exe [选项]

  --mode <system|hosts|pac|dns|proxyonly>  运行模式，默认 system
  --port <端口>                            代理监听端口，默认 26501（hosts / dns 模式固定 443）
  --ip <地址>                              监听地址，默认 127.0.0.1
  --dns <地址>                             上游 DNS，默认 223.5.5.5
  --no-doh                                 关闭 DoH
  --all                                    忽略配置文件里的开关，启用全部规则
  --exclude <项目名>[,<项目名>...]        按项目名排除规则，可重复指定
  --rules <路径>                          指定规则配置文件，默认 <数据目录>\accelerate-rules.json
  --refresh-rules                         从官方接口重新拉取规则并更新配置文件
  --console                               保持控制台窗口可见（默认启动后转入托盘并隐藏窗口）
  --help                                   显示帮助
```

## 五种模式

| 模式 | 命令行 | 作用 | 需要管理员 |
|---|---|---|---|
| `dns` | `--mode dns` | WinDivert 驱动级 DNS 拦截，命中域名解析到本机 | **是** |
| `system` | `--mode system` | 设置 Windows 系统代理（`ProxyEnable`/`ProxyServer`） | 否 |
| `pac` | `--mode pac` | 写 `AutoConfigURL`，由引擎自带 PAC 脚本分流 | 否 |
| `hosts` | `--mode hosts` | 改写 hosts 指向本机，反代监听 443/80 | 否 |
| `proxyonly` | `--mode proxyonly` | 只提供 HTTP 代理端口，不改任何系统设置 | 否 |

`dns` 模式覆盖最彻底且不依赖系统代理设置，推荐日常使用。
`system` 模式适合不方便改 DNS 的场景。

## Google 能不能加速

**`google.com` / `www.google.com` 本身不能加速。** 规则集里唯一匹配它的是
`Google(Recaptcha) 验证码`（转发到 `www.recaptcha.net`），用途是让页面里的 reCAPTCHA 组件
能加载，不是把 Google 搜索代理出来。启用它只会让 Google 首页变成 404。

能加速的是 Google 的 API / 字体类域名：

| 域名 | 转发到（国内镜像） | 实测 |
|---|---|---|
| `ajax.googleapis.com` | `ajax.proxy.ustclug.org` | 200 |
| `fonts.googleapis.com` | `fonts.font.im` | 200 |
| `fonts.gstatic.com` | `gstatic.loli.net` | 200 |
| `themes.googleusercontent.com` | `themes.loli.net` | 200 |

要开这几条，把配置文件里对应的 `enabled` 改成 `true` 即可；
同时确认 `Google(Recaptcha) 验证码` 那条是 `false`。

## 端口说明

| 模式 | 实际监听 |
|---|---|
| `system` / `pac` / `proxyonly` | `--port` 指定的正向代理端口（默认 26501） |
| `hosts` / `dns` | 引擎固定监听 `443` / `80` 做反向代理，`--port` 对这两种模式无效 |

## 数据与日志

| 用途 | 路径 |
|---|---|
| 数据目录 | `%LOCALAPPDATA%\Steam++Accelerator` |
| 规则配置 | `<数据目录>\accelerate-rules.json` |
| 官方规则原始缓存 | `<数据目录>\accelerate-projects.json` |
| 运行日志 | `<数据目录>\Cache\Logs\accelerator-<日期>.log` |

## 停止与清理

- 正常停止：右键托盘图标 → 「退出」。程序会先撤销自己写入的系统设置（系统代理 / PAC / hosts），
  再关闭引擎。启动后若程序自身抛异常退出，同样会撤销系统设置。
- 强杀进程（任务管理器结束）：`system` / `pac` 写下的注册表项**不会**被撤销，需要手动关闭：
  ```bat
  reg add "HKCU\Software\Microsoft\Windows\CurrentVersion\Internet Settings" /v ProxyEnable /t REG_DWORD /d 0 /f
  reg delete "HKCU\Software\Microsoft\Windows\CurrentVersion\Internet Settings" /v AutoConfigURL /f
  ```
  hosts 模式下需要手动删除 `C:\Windows\System32\drivers\etc\hosts` 中
  `# --- Steam++Accelerator BEGIN ---` 到 `# --- Steam++Accelerator END ---` 之间的整段。

## 注意事项

- `--ip` 默认只监听 `127.0.0.1`。改成 `0.0.0.0` 会把 MITM 代理暴露给同网段所有设备，别这么做。
- `dns` 模式必须管理员运行（要加载 WinDivert 驱动）。`WinDivert.dll` / `WinDivert64.sys` 已在安装目录内。
- 规则配置文件写坏了程序会报错退出并保留原文件，不会静默覆盖你的改动。
- 部分站点（如 `raw.githubusercontent.com`）不在规则的匹配域名里，走直连，不受影响。
